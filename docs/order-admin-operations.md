# Brega Chai — работа с заказами в Strapi Admin

## Доступ

В разделе Settings → Administration panel → Roles назначаются независимые
действия плагина «Заказы»:

- «Просмотр заказов» — открыть список и карточку;
- «Изменение статуса заказа» — дополнительно выполнять разрешённые переходы.

Менеджеру, который только сверяет заказы, достаточно просмотра. Право изменения
статуса не следует выдавать автоматически вместе с просмотром. Доступ к
стандартной сущности Order в Content Manager рабочей роли не требуется.

## Обработка заказа

1. Открыть «Заказы» в основном меню.
2. Найти заказ по номеру или имени; при необходимости ограничить статус и даты.
3. Открыть номер заказа и сверить контакты, адрес, комментарий, состав и сумму.
4. Для принятого заказа выбрать «Перевести: подтверждён».
5. После выполнения выбрать «Перевести: выполнен».
6. При отмене прочитать предупреждение и подтвердить действие: остатки
   возвращаются один раз транзакционной commerce-логикой.

Контакты, адрес, позиции, цены и сумма являются snapshot заказа и в этом
интерфейсе не редактируются. Если статус уже изменил другой менеджер, команда
будет отклонена; нужно обновить карточку и проверить актуальное состояние.

## Диагностика

- безопасная ошибка загрузки не означает изменения заказа — повторите запрос;
- ошибка status action оставляет прежний статус;
- отсутствие действий означает terminal status либо отсутствие permission;
- application log для перехода содержит только document ID, исходный/целевой
  статус, administrator ID, результат и error code; PII не логируется.
